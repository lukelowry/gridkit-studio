# GridKit Studio

Open a case, select an element, and explore it in Network, Diagram, Case, or JSON.

Right-click a `.solver.json` and choose **Run Dynamic Simulation** or **Run Contingency Analysis**. GridKit runs the solver file where it is, and the Monitor plots what it writes. **Monitored Signals** chooses what the case records, and the Monitor's controls replay the run and step through samples.
