# Cases

These cases were copied through Lattice from [GridKit's PhasorDynamics cases](https://github.com/ORNL/GridKit/tree/main/cases/PhasorDynamics).
GridKit provides the dynamics models; the original networks are credited below.

| Cases | Original source |
| --- | --- |
| ACTIVSg200, ACTIVSg500, ACTIVSg2000, ACTIVSg10k | [Texas A&M synthetic grids](https://electricgrids.engr.tamu.edu/electric-grid-test-cases/) |
| Hawaii, IEEE39 | [Texas A&M test case repository](https://electricgrids.engr.tamu.edu/electric-grid-test-cases/), as credited by GridKit |
| WECC240 | [National Laboratory of the Rockies test case repository](https://www.nlr.gov/grid/test-case-repository), as credited by GridKit |

Luke Lowery adapted numeric formatting, monitor selections, fault examples, and solver configurations for GridKit Studio. These are maintained examples, not an automatically synchronized copy of upstream.

The upstream license, acknowledgment, and disclaimer are preserved in [Third-party notices](../THIRD_PARTY_NOTICES.md#gridkit-case-data-and-test-fixtures).
